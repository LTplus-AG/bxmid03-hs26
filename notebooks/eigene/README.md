# Eigene Notebooks

Hier dürfen Lehrperson und Studierende Notebooks ablegen, die nicht zu einem Team-Repository gehören (z. B. Experimente, Lösungsideen für alle).

**Aus Colab speichern:** *Datei → Kopie in GitHub speichern* → Repository `LTplus-AG/bxmid03-hs26` → Pfad `notebooks/eigene/<name>_<thema>.ipynb` → Commit-Nachricht schreiben.

Team-Notebooks gehören ins eigene Team-Repository (`LTplus-AG/bxmid03-hs26-team-N`, Ordner `checks/`).
